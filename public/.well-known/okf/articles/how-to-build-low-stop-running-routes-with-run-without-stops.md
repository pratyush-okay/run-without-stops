# How to Build Low-Stop Running Routes with Run Without Stops

A low-stop line is [low-stop routing](../concepts/low-stop-routing.md) switched on: drop a start and finish, leave traffic lights, highways, and busy roads visible, then move a waypoint until remaining waits are ones you chose.

# Run Without Stops

Run Without Stops is a free map-first running route planner. Click the map, search a place anywhere, or start from where you are, then get a quieter pedestrian line that can skip lights, highways, and busy roads.

Coverage is worldwide. The map still opens on Sydney when the browser has no location. Sign-in is optional and is only used to save and share routes at `/r/[slug]`. There are no paid plans.

## What this business does

The product is the homepage map at [https://www.runwithoutstops.com](https://www.runwithoutstops.com/). Crawlable notes live at [/blog](https://www.runwithoutstops.com/blog). Overlays (traffic lights, crossings, drinking water, parks, highways, busy roads) load when the map is zoomed into streets, not at country scale.

Low-stop mode prefers streets with fewer signals and keeps off highways and busy roads when a quieter alternative exists. Direct mode draws the more literal pedestrian line. Avoid elevation is a separate switch for hills.

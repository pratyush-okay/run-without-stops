# The Complete Guide to Building a Run Without Stops

A run without stops is a pedestrian line you can keep moving on: fewer red lights, fewer highway edges, fewer busy-road squeezes. [Run Without Stops](../index.md) is a free worldwide planner. Click a start, search a place, or start from where you are, then choose low-stop or direct.

[Low-stop routing](../concepts/low-stop-routing.md) prefers streets with fewer traffic lights and keeps off highways and busy roads when a quieter alternative exists. Direct draws the more literal line. Avoid hills only appears under Low stops. Overlays (lights, crossings, water, parks, highways, busy roads) load at street zoom, not country scale.

The map opens on Sydney when the browser has no location. Coverage is not Sydney-only. Canonical live URL: [the complete guide](https://www.runwithoutstops.com/blog/the-complete-guide-to-building-a-run-without-stops).

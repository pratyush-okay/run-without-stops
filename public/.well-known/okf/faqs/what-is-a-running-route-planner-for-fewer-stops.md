# What is a running route planner for fewer stops?

A planner that can see traffic lights, highways, and busy roads on the same map you draw, then build a pedestrian line that skips them when you ask. [Run Without Stops](../index.md) does that worldwide, for free.

Low-stop mode is that request. Direct mode is the shorter legal pedestrian line. See [low-stop routing](../concepts/low-stop-routing.md).
